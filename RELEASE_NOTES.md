# Remy 0.9.0 Beta 1

Remy is a focused macOS menu bar companion for Apple Reminders.

## What you can test

- Create, edit, complete, delete and filter Apple Reminders without opening the Reminders app.
- Use natural-language dates, times, lists, priorities, recurrence, notes, URLs and locations.
- Plan reminders visually in My Day without changing their Apple Reminders due dates.
- Opt individual reminders into Intensive Mode for local follow-up notifications and Notch feedback.
- Create reminders from selected text through the macOS Services menu.

## Before installing

- Requires macOS 14 or later on Apple silicon or Intel.
- Requires a beta activation key and an internet connection for the first activation.
- This is pre-release software. Keep Apple Reminders available for time-critical tasks.
