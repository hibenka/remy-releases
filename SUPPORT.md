# Support

No activation key, reminder content or private diagnostic data should be posted in a public GitHub issue.

The private installation and activation support form will be linked here before the first downloadable beta is published. Until then, the release is not ready for external testers.

For a reproducible application bug, the public [issue tracker](https://github.com/hibenka/remy-releases/issues) may be used without including reminder titles, notes, licence keys or other personal information.
