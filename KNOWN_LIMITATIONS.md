# Known limitations

- This is pre-release software and should not be the only way you manage time-critical tasks.
- The beta requires macOS 14 or later.
- Activation requires an internet connection the first time. A valid offline certificate then remains usable until its expiry.
- Intensive Mode creates Remy local notifications only. It does not add follow-up alarms to Apple Reminders.
- Early alerts are local Remy notifications so Apple Reminders keeps displaying the original due time.
- Remy never promises to set an “Urgent” state in Apple Reminders.
- Updates are checked manually or at most once per day. Remy opens the download page and does not install updates automatically.
- The “Create Reminders with Remy” text-selection Service is available from the Services menu. macOS may place it under Services rather than directly in the contextual menu.

Release-specific limitations will be added to each GitHub Release.
